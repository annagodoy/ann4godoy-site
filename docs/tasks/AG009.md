# AG009 — Baseline de arquitetura e documentação

## Objetivo

Atualizar a documentação para refletir a arquitetura real da Issue 001 e registrar as decisões técnicas importantes tomadas durante sua construção.

**Status:** concluída.

## Problema

O README ainda descreve apenas a estrutura inicial do projeto e aponta somente para a primeira tarefa. A aplicação agora possui coleções locais, componentes editoriais, ilhas React e integrações com players externos, mas essas decisões ainda não estão registradas como baseline arquitetural.

## Decisão técnica

- Documentar somente a arquitetura que já existe.
- Atualizar o README como porta de entrada operacional do projeto.
- Criar ADRs apenas para decisões com alternativas e consequências relevantes.
- Registrar separadamente arquitetura static-first, conteúdo local validado e hidratação seletiva.
- Não introduzir novas tecnologias durante esta tarefa.
