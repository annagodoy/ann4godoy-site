# AG002 — Direção visual da Issue 001

## Objetivo

Transformar a estrutura semântica da **ANN4GODOY — Issue 001: Warm Graphite** em uma primeira composição editorial responsiva, acessível e sem JavaScript no cliente.

**Status:** concluída.

## Decisão técnica

- Manter tokens, reset e fundamentos do documento nos estilos globais.
- Manter estilos específicos dentro dos respectivos componentes Astro.
- Usar estilos escopados do Astro para evitar vazamentos entre componentes.
- Usar estilos escopados na homepage somente para sua composição e suas seções.
- Não adicionar framework CSS, pré-processador ou biblioteca de componentes.

Referências:

- [Astro Components](https://docs.astro.build/en/basics/astro-components/)
- [Astro — Styles and CSS](https://docs.astro.build/en/guides/styling/)

## Objetivos de estudo

Esta tarefa trabalha:

- estilos escopados em componentes Astro;
- cascata, herança e especificidade;
- design tokens orientados a uso;
- CSS Grid e fluxo normal do documento;
- tipografia fluida com `clamp()`;
- breakpoints orientados pelo conteúdo;
- responsividade mobile-first;
- estados de interação e acessibilidade;
- separação entre estilos globais, de componente e de página;
- validação visual incremental.
