# AG008 — Contato e booking

## Objetivo

Adicionar uma seção editorial de contato que ofereça um caminho claro para propostas e solicitações de booking.

**Status:** concluída.

## Problema

A homepage apresenta a identidade e o trabalho musical da ANN4GODOY, mas ainda não oferece uma forma explícita de iniciar um contato profissional.

## Decisão técnica

- Usar a chamada editorial `Vamos criar um encontro`.
- Usar o texto de apoio `Para bookings, colaborações e projetos, entre em contato.`.
- Disponibilizar o e-mail `ann4godoy@gmail.com` por meio de um link `mailto:`.
- Exibir inicialmente apenas o Instagram `@ann4godoy` como canal social.
- Implementar a seção com Astro e HTML semântico.
- Manter a solução funcional sem JavaScript.
- Adiar formulário, backend e persistência até existir uma necessidade real para o domínio de booking.
