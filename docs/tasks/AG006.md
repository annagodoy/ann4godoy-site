# AG006 — Arquivo editorial Te convido para um Date

## Objetivo

Substituir o placeholder da seção `Te convido para um Date` por um arquivo editorial das edições publicadas pela Function FM, com descrições próprias e reprodução pelo player existente.

**Status:** concluída.

## Problema

A série possui dois episódios reais, textos editoriais e identidade própria, mas ainda não é validada ou apresentada pelo site. Os registros precisam permanecer independentes do catálogo genérico de sets e da série Maremoto.

## Decisão técnica

- Usar o `id="date-invites"` na seção e na navegação interna.
- Preservar os IDs `tcpud-1` e `tcpud-2` definidos no inventário.
- Criar uma coleção local específica chamada `dateInvites`.
- Tratar `Te convido para um Date` como uma série composta por episódios.
- Manter as descrições como conteúdo editorial de cada episódio.
- Ordenar as edições da mais recente para a mais antiga durante a consulta.
- Reutilizar o `SetPlayer` e o adaptador SoundCloud existentes.
- Manter links externos como fallback sem JavaScript.

Referências:

- [Astro — Content Collections](https://docs.astro.build/en/guides/content-collections/)
- [Astro — Components](https://docs.astro.build/en/basics/astro-components/)
