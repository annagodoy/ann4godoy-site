# AG004 — Player multimídia experimental com React

## Objetivo

Adicionar à seção `Sets` um player incorporado para YouTube e SoundCloud, usando uma ilha React como exercício de interatividade no Astro sem transformar toda a página em uma aplicação cliente.

**Status:** concluída.

## Problema

O catálogo atual leva a pessoa para uma plataforma externa. O player permitirá ouvir um set sem abandonar o site, preservando os links externos como fallback e evitando introduzir backend, autenticação ou sincronização com APIs antes de existir essa necessidade.

## Decisão técnica proposta

- Usar a integração oficial `@astrojs/react` somente na área interativa do player.
- Manter a consulta da coleção e a renderização do catálogo no Astro.
- Passar ao React somente dados serializáveis necessários à interação.
- Usar os embeds oficiais do YouTube e do SoundCloud.
- Carregar o iframe somente depois de uma escolha explícita.
- Não iniciar áudio ou vídeo automaticamente.
- Exibir apenas um player por vez.
- Preservar em cada set o link externo para a plataforma original.
- Começar com os controles nativos dos provedores antes de avaliar controles próprios.
- Não usar YouTube Data API nem SoundCloud REST API nesta versão.

Referências:

- [Astro — React integration](https://docs.astro.build/en/guides/integrations-guide/react/)
- [Astro — Framework components](https://docs.astro.build/en/guides/framework-components/)
- [YouTube — IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)
- [SoundCloud — Widget API](https://developers.soundcloud.com/docs/api/html5-widget)

## Contrato inicial de interação

1. A página continua exibindo o catálogo mesmo sem JavaScript.
2. Cada entrada oferece uma ação clara para abrir o set no player e mantém o link externo existente.
3. Ao selecionar um set, a região do player informa qual conteúdo foi escolhido.
4. O iframe correspondente é criado somente após essa seleção.
5. Uma nova seleção substitui o player atual em vez de criar players adicionais.
6. A reprodução começa apenas por ação da pessoa nos controles do provedor.
7. Se o embed falhar, o link externo permanece disponível.
8. Mudanças relevantes de seleção são comunicadas de forma acessível sem mover o foco inesperadamente.

## Fora do escopo

- player visual totalmente customizado;
- reprodução automática;
- reprodução simultânea de vários sets;
- YouTube Data API;
- SoundCloud REST API;
- OAuth ou contas das plataformas;
- backend, banco de dados ou proxy de mídia;
- sincronização automática do catálogo;
- analytics de reprodução;
- fila, playlist ou reprodução contínua entre plataformas;
- controle global persistente entre páginas.

## Paralelos com Rails

| Astro + React | Rails |
| --- | --- |
| Ilha hidratada | Componente enriquecido por Stimulus |
| Props serializáveis | Dados expostos pela view ao controlador cliente |
| Estado local do player | Estado de interface no navegador |
| Adaptador por plataforma | Adapter ou gateway de serviço externo |
| Link externo como fallback | Progressive enhancement sobre HTML funcional |

## Definição de pronto

A AG004 estará concluída quando uma pessoa puder selecionar e reproduzir qualquer set no player incorporado, os links externos continuarem funcionais sem JavaScript, apenas a ilha necessária for hidratada e todas as validações estiverem concluídas.
