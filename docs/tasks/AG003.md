# AG003 — Catálogo editorial de sets

## Objetivo

Substituir o placeholder da seção `Sets` por um catálogo editorial com os sets publicados por ANN4GODOY no YouTube e no SoundCloud.

**Status:** concluída.

## Decisão técnica

- Armazenar os sets em uma coleção de conteúdo local carregada no build.
- Usar um único arquivo JSON como fonte de dados nesta primeira versão.
- Validar o formato dos registros por meio de um schema.
- Armazenar `publishedAt` no formato ISO `YYYY-MM-DD`.
- Ordenar os sets do mais recente para o mais antigo durante a consulta.
- Formatar datas somente na camada de apresentação.
- Manter links externos como fallback permanente para as plataformas.

Referências:

- [Astro — Content Collections](https://docs.astro.build/en/guides/content-collections/)
- [Astro Components](https://docs.astro.build/en/basics/astro-components/)

## Modelo inicial

```ts
type SetPlatform = "youtube" | "soundcloud";

interface Set {
  id: string;
  title: string;
  platform: SetPlatform;
  url: string;
  publishedAt: Date;
}
```

O `id` identifica cada entrada dentro da coleção.

## Paralelos com Rails

| Astro | Rails |
| --- | --- |
| Schema da coleção | Validações do model |
| Entrada da coleção | Registro de domínio somente leitura |
| `getCollection()` | Consulta no model/repository |
| Ordenação na página | Escopo ou query ordenada |
| `SetItem` | ViewComponent ou partial tipado |
| Build inválido por dado incorreto | Falha de validação antes da publicação |
