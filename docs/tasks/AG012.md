# AG012 — Deploy estático no Cloudflare Workers

## Objetivo

Publicar a Issue 001 em uma URL gratuita `workers.dev` e automatizar novos deploys a partir da branch `main`, preservando a arquitetura static-first.

**Status:** concluída.

## Problema

O projeto possui repositório público, quality gate e CI, mas ainda não existe uma versão acessível fora do ambiente local. O deploy precisa servir o diretório estático `dist/` sem introduzir renderização no servidor.

## Decisão técnica

- Usar Cloudflare Workers Static Assets.
- Usar a URL gratuita `workers.dev` nesta fase.
- Manter o output estático padrão do Astro.
- Não instalar `@astrojs/cloudflare` nem adicionar código Worker.
- Configurar Wrangler apenas para publicar o diretório `dist/`.
- Usar Workers Builds conectado ao GitHub para deploy contínuo.
- Executar check e build antes do deploy remoto.
- Fixar Node.js 22 para manter consistência entre desenvolvimento, CI e CD.
- Adiar domínio próprio para uma tarefa futura.

Referências:

- [Cloudflare — Astro no Workers](https://developers.cloudflare.com/workers/framework-guides/web-apps/astro/)
- [Cloudflare — Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/)
- [Cloudflare — Static Assets](https://developers.cloudflare.com/workers/static-assets/)
