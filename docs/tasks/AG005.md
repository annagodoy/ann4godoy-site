# AG005 — Arquivo editorial Maremoto Sessions

## Objetivo

Substituir o placeholder da seção `Maremoto` por um arquivo editorial das sessões publicadas pela Function FM, preservando os nomes artísticos e permitindo ouvir cada episódio dentro da página.

**Status:** concluída.

## Problema

O projeto já possui quatro episódios reais de Maremoto Sessions, mas eles ainda não são validados, consultados ou apresentados no site. A série possui identidade, numeração e DJs próprios, portanto não deve ser reduzida a registros genéricos do catálogo principal de sets.

## Decisão técnica

- Criar uma coleção local específica para `maremotoSessions`.
- Tratar Maremoto como uma série editorial composta por episódios.
- Manter no registro somente os dados variáveis de cada episódio.
- Representar a numeração como inteiro e formatá-la apenas na apresentação.
- Preservar o nome de exibição do DJ, mesmo quando o slug histórico da plataforma for diferente.
- Ordenar os episódios do mais recente para o mais antigo durante a consulta.
- Reutilizar o player React existente por meio de um mapeamento explícito para `PlayerSet`.
- Manter links externos como fallback sem JavaScript.

Referências:

- [Astro — Content Collections](https://docs.astro.build/en/guides/content-collections/)
- [Astro — Components](https://docs.astro.build/en/basics/astro-components/)
