## Objetivos de estudo

Esta tarefa trabalha:

- anatomia de componentes Astro;
- props com TypeScript;
- separação entre layout, componente e página;
- design tokens com CSS;
- HTML semântico;
- responsividade e acessibilidade;
- composição no servidor sem JavaScript desnecessário;
- critérios de aceite e evolução incremental.

## Paralelos com Rails

| Astro | Rails |
| --- | --- |
| Page | Controller action + view de entrada |
| Layout | Application layout |
| Component | Partial ou ViewComponent |
| Props | Locals ou argumentos tipados |
| Design tokens | Variáveis compartilhadas do design system |
